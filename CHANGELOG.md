# BetterLoot Changelog

## v0.1.0

- Replaces Blizzard's group-loot window with compact, stacked roll bars.
- Supports Need, Greed, Transmog, Disenchant, and Pass choices.
- Adds item details, quality-colored timers, tooltips, and roll queuing.
- Adds a movable position with account-wide persistence.
- Adds a 32×32 addon-list icon.
